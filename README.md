# Google Drive HTML 文章阅读器 (Drive Article Reader)

专为阅读 Google Drive 中的 HTML 格式网页与文章打造的现代化 Web 阅读器。提供纯净舒适的排版阅读模式与原汁原味的网页展示模式，全方位深度适配移动端触屏与桌面宽屏。

---

## ✨ 核心特性

- 🌐 **直接连接 Google Drive**：通过官方 OAuth 2.0 授权，免梯直接读取云端硬盘中的 `.html` / `.htm` 网页与文章。
- 📱 **全方位移动端适配 (Mobile-First)**：
  - **抽屉式侧边栏 (Drawer)**：小屏下文件列表与目录大纲自动转为滑出抽屉，支持遮罩与单手滑动。
  - **移动端悬浮底栏 (Mobile Bottom Bar)**：单手拇指即可唤出目录、调节字号、切换主题。
  - **自适应沉浸阅读**：向上轻滑阅读自动收起控制栏，向下轻滑或点击屏幕重新显现。
  - **刘海屏与安全区域**：针对 iPhone/Android 底部横条与刘海全面适配 Safe Area Insets。
- 📖 **双模式阅读体验**：
  - **纯净阅读模式 (Clean Mode)**：内置 `@mozilla/readability` 与 DOMPurify，去除杂质与商业噪音，还原优雅的书籍排版。
  - **原始网页模式 (Raw Mode)**：沙箱化 `<iframe>` 隔离渲染，完美保留原版样式与多媒体交互。
- 🎨 **丰富的阅读主题与排版微调**：
  - 5 种精选阅读主题：**浅色 (Light)**、**羊皮纸 (Sepia)**、**护眼绿 (EyeGreen)**、**暗黑 (Dark)**、**午夜蓝 (Midnight)**。
  - 4 种字体族自由切换：衬线体、无衬线体、楷体、等宽代码字体。
  - 字号逐级微调（A- / A+）、段落行距与正文版心宽度调节。
- 📑 **智能文章大纲 (TOC & Scrollspy)**：
  - 自动解析 `h1` ~ `h6` 标题生成层级目录。
  - 点击平滑滚动定位，滚动时自动追踪当前阅读章节。
- 🔍 **正文检索与高亮**：文章内关键词即时查找，展示匹配总数并自动高亮匹配文本。
- 💾 **阅读进度与历史自动记忆**：本地自动保存阅读百分比与滚动位置，再次打开时无缝续读。
- 🔒 **纯前端隐私安全**：用户凭据与 OAuth Token 仅保存在浏览器本地，不经过任何中转服务器。
- 💡 **内置开箱即用演示文章**：无需立即配置 Google 凭据，开箱即可体验完整阅读功能。

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

### 3. 构建生产包
```bash
npm run build
```

## 🔑 Google Drive API 配置指南 (3 分钟)

1. 前往 [Google Cloud Console](https://console.cloud.google.com/) 并创建或选择一个项目。
2. 在 **API 和服务** > **库** 中搜索 **Google Drive API** 并点击 **启用**。
3. 在 **OAuth 同意屏幕** 中：
   - 用户类型选择 **外部 (External)**。
   - 填写应用名称（如 `Drive Reader`）与开发者邮箱，点击保存。
4. 在 **凭据** 页面：
   - 点击 **创建凭据** > **OAuth 客户端 ID**。
   - 应用类型选择 **Web 应用程序**。
   - 在 **已获授权的 JavaScript 来源** 中添加本地调试地址：
     `http://localhost:3000` (如需线上部署，请同时添加线上域名)。
   - 点击创建，复制生成的 **Client ID (客户端 ID)**。
5. 打开阅读器右上角 **设置 (⚙️ 图标)**，粘贴你的 Client ID 并点击保存。
6. 点击右上角 **连接 Drive** 即可一键完成授权登录。
